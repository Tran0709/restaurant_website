# 菜园子 原味湘菜 — Restaurant Website

Introduction website for 菜园子 (Authentic Hunan Cuisine), 118 Killiney Road #01-02, Singapore 239555 · 6041 9403.

- `index.html` – the introduction site (story, promises, signature dishes, menu, gallery, reservations, visit us)
- `order/` – the online ordering app (not linked from the website until payments are connected)
- `img/` – dish photos and logo

Run locally:

    python -m http.server 8000

then open http://localhost:8000
